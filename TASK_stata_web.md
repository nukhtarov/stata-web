# Задача: браузерный тренажёр Stata для регрессионного анализа

## Цель

Сделать статическое веб-приложение, которое работает в браузере без установки и повторяет ту часть Stata, которую проходят на курсе эконометрики: загрузка Excel, описательная статистика, МНК-регрессия и диагностика предпосылок П1–П5.

Пользователь вводит **команды в синтаксисе Stata** (с автодополнением) или запускает do-файл и получает:

1. **Вывод, максимально похожий на Stata**: те же таблицы, те же числа, то же форматирование чисел.
2. **Пояснение под каждым выводом**: вердикт «хорошо / плохо», объяснение простыми словами и готовая фраза для отчёта.

Целевой пользователь — студент без опыта, который не понимает терминов. Пояснения должны быть понятны без знания статистики.

**Главный критерий приёмки:** на эталонном датасете все числа совпадают с выводом настоящей Stata 14 (эталон — в разделе «Приёмка»).

## Стек

- Vite + TypeScript, без тяжёлых фреймворков (vanilla TS или Preact).
- Чтение Excel: SheetJS (`xlsx`).
- Графики: собственный SVG-рендер (scatter, line, overlay). Без Chart.js и аналогов — нужен полный контроль над видом, как в Stata.
- Тесты: Vitest. Эталонные значения считать в Python (numpy, scipy, statsmodels) и хранить в `tests/fixtures/*.json`.
- Сборка в статику, деплой на GitHub Pages. Без бэкенда: все вычисления в браузере.
- UI: Svelte 5 + TypeScript на Vite (`npm create vite@latest -- --template svelte-ts`), без SvelteKit.
- Только синтаксис Svelte 5 (runes): `$state`, `$derived`, `$effect`, `$props`, `$bindable`,
  обработчики `onclick={...}`, сниппеты `{#snippet}` / `{@render}`.
  ЗАПРЕЩЕНО: `export let`, реактивные `$:`, `on:click`, `createEventDispatcher`, `<slot>`.
  Глобальное состояние — в `.svelte.ts` модулях с `$state`, не в svelte/store.
- Ядро (`src/stats`, `src/lang`, `src/data`, `src/explain`) — чистый TS без импортов из svelte;
  UI только вызывает его и рендерит результат.
- Редактор do-файлов и командная строка — CodeMirror 6 (@codemirror/autocomplete, свой language-пакет
  для подсветки команд Stata, комментариев `*` и `//`). Источник автодополнения — общий модуль
  `src/lang/completions.ts` (команды, переменные текущего датасета, опции команды).
- Тесты UI: Vitest + @testing-library/svelte; E2E — Playwright.

## Интерфейс

Раскладка как в Stata, но современная:

- **Слева сверху — Variables.** Список переменных с типом. Клик вставляет имя в командную строку.
- **Слева снизу — Review.** История команд. Клик вставляет команду, двойной клик выполняет её.
- **Центр — Results.** Лента результатов. Каждая команда — отдельная карточка:
  - эхо команды (`. reg Price Gini …`);
  - вывод в стиле Stata: моноширинный шрифт, таблицы с разделителями `|` и `-+-`;
  - для графиков — SVG-график, кнопка «скачать PNG»;
  - **блок пояснения**, сворачиваемый и включаемый глобальным тумблером «Показывать пояснения»:
    - вердикт-пилюля: ✓ зелёная «хорошо» / ✗ красная «плохо» / ℹ серая «информация»;
    - 2–4 предложения простыми словами с подставленными числами;
    - «Что записать в работу» — готовая фраза с числами и кнопка «Скопировать».
- **Низ — командная строка.** Автодополнение, история по ↑/↓, Enter — выполнить.
- **Вкладка Do-file Editor.** Textarea с подсветкой синтаксиса (команды, комментарии `*` и `//`, строки):
  - Ctrl+D (⌘+D на Mac) — выполнить выделенное, а без выделения — весь файл;
  - кнопки «Выполнить всё» и «Выполнить выделенное»;
  - по умолчанию предзаполнен учебным do-файлом (ниже);
  - содержимое сохраняется в localStorage (с try/catch).
- **Загрузка данных:** кнопка «Открыть Excel», drag & drop файла на страницу и команда `import excel` (см. ниже).
- Светлая и тёмная тема (по системной настройке плюс переключатель).
- Адаптивность до ширины планшета; телефон — по возможности, не приоритет.
- Кнопка «Экспорт отчёта»: собрать все карточки с пояснениями в печатный вид (print CSS) → PDF через системную печать.

### Автодополнение

- Позиция 1 — имена команд и их сокращения (`reg`/`regress`, `sum`/`summarize`, `des`/`describe`, `corr`/`correlate`, `gen`/`generate`…) с короткой подсказкой на русском: «reg — линейная регрессия (МНК)».
- После команды — имена переменных из датасета, с фильтром по префиксу и с учётом уже введённых.
- После запятой — опции этой команды (`detail`, `normal`, `lowess`, `yline()`, `resid`, `xb`, `firstrow`, `clear`, `sheet()`).
- После `estat` — подкоманды `imtest`, `hettest`.
- Внутри `twoway (` — `scatter`, `lfit`.
- Tab или Enter — принять, Esc — закрыть, ↑/↓ — навигация.
- Под строкой ввода — подсказка синтаксиса текущей команды: `regress depvar [indepvars] [, options]`.

### Импорт Excel

- Имена переменных из первой строки при `firstrow` приводить по правилам Stata `strtoname()`: недопустимые символы → `_`, имя с цифры → префикс `_`, обрезка до 32 символов. Например, «Euro area» → `Euro_area`. Без `firstrow` имена `A, B, C…`.
- Типы: числовые столбцы → `double` (или `byte/int`, если все значения целые и укладываются в диапазон); текстовые → `str#`, где # — максимальная длина.
- Пустые ячейки → missing (`.`).
- Если столбец текстовый, но значения — числа с запятой («1234,5»), импортировать как `str`, как это делает Stata, и показать подсказку: «похоже на числа с запятой → `destring X, replace dpcomma`».

## Формулы

Обозначения: N — наблюдения, k — число параметров с константой, e — остатки МНК, ŷ — прогноз.

**Важно:** формулы `estat imtest` (компоненты skewness и kurtosis) и детали `kdensity`/`lowess` **сверить с Stata Manual**: [R] regress postestimation → Methods and formulas, [R] kdensity, [R] lowess. Критерий корректности — совпадение с эталоном.

### Распределения

- Φ и Φ⁻¹: Φ — через erfc с высокой точностью, Φ⁻¹ — алгоритм AS 241 (PPND16).
- t, F: через регуляризованную неполную бета-функцию (непрерывная дробь Лентца).
- χ²: через регуляризованную неполную гамма-функцию.
- Квантиль t для доверительного интервала: численное обращение CDF (Ньютон или бисекция до 1e-12).

### regress

- b = (X'X)⁻¹X'y через QR; s² = RSS/(N−k); V = s²(X'X)⁻¹.
- F = (MSS/(k−1)) / (RSS/(N−k)); R² = MSS/TSS; Adj R² = 1 − (1−R²)(N−1)/(N−k); Root MSE = √s².
- CI = b ± t₀.₉₇₅,N−k · se.

### linktest

Регрессия y на `_hat` = ŷ и `_hatsq` = ŷ² с константой, на выборке модели. Вывести полную таблицу regress с именами `_hat`, `_hatsq`, `_cons`. После — восстановить исходную модель.

### ovtest (RESET, Stata default)

- ŷ отмасштабировать к [0,1]: z = (ŷ − min)/(max − min). На F это не влияет, но улучшает численную точность.
- Длинная модель: X + z² + z³ + z⁴.
- F = ((RSS_r − RSS_u)/3) / (RSS_u/(N − k − 3)), df = (3, N−k−3).
- Вывод:
  ```
  Ramsey RESET test using powers of the fitted values of Price
         Ho:  model has no omitted variables
                    F(3, 28) =      6.25
                    Prob > F =      0.0022
  ```

### vif

Для каждого регрессора j: R²ⱼ из регрессии xⱼ на остальные регрессоры с константой. VIF = 1/(1−R²ⱼ), колонка 1/VIF. Сортировка по убыванию VIF, строка `Mean VIF`.

### swilk (Royston)

- W — коэффициенты по алгоритму AS R94 (как в `scipy.stats.shapiro`; можно портировать `swilk.c` из scipy).
- Для N ≥ 12 (N в диапазоне 4…11 — отдельная гамма-формула из AS R94):
  - μ = 0.0038915·(ln N)³ − 0.083751·(ln N)² − 0.31082·ln N − 1.5861;
  - ln σ = 0.0030302·(ln N)² − 0.082676·ln N − 0.4803;
  - z = (ln(1−W) − μ)/σ;
  - **V = (1−W)/exp(μ)** (проверено на эталоне: W = 0,98742, N = 48 → V = 0,573, z = −1,185);
  - Prob>z = 1 − Φ(z).
- Вывод: таблица `Variable | Obs W V z Prob>z`.

### estat hettest (по умолчанию: Breusch–Pagan / Cook–Weisberg по fitted values)

- σ̂² = RSS/N (ML-оценка).
- Регрессия gᵢ = eᵢ²/σ̂² на ŷ с константой.
- χ² = MSS/2, df = 1.
- Вывод:
  ```
  Breusch-Pagan / Cook-Weisberg test for heteroskedasticity
           Ho: Constant variance
           Variables: fitted values of Price

           chi2(1)      =     1.33
           Prob > chi2  =   0.2483
  ```

### estat imtest (Cameron & Trivedi decomposition)

- **Heteroskedasticity:** N·R² из регрессии e² на константу и все уникальные элементы xx' (сами регрессоры, их квадраты и попарные произведения). Коллинеарные столбцы исключаются (например, квадрат дамми = дамми). df = число оставшихся неконстантных столбцов. На эталоне 16 факторов и N = 48 дают насыщенную вспомогательную регрессию: R² = 1, χ² = 48.00, df = 47. Исключение коллинеарных столбцов должно быть устойчивым.
- **Skewness** (df = k−1 = 16) и **Kurtosis** (df = 1): **формулы взять из Stata Manual** и подтвердить эталоном: 11.72 / 16 / 0.7629 и 0.62 / 1 / 0.4321.
- **Total:** сумма трёх χ² и сумма df.
- Опция `white`: классический тест Уайта (N·R²).
- Если df вспомогательной регрессии ≥ N−1, в пояснении показать предупреждение: «тест перегружен, слишком много переменных для числа наблюдений → опирайтесь на hettest».

### kdensity

- Ядро Epanechnikov в варианте Stata: K(u) = 3/(4√5)·(1 − u²/5) при |u| < √5.
- Полоса по умолчанию: h = 0.9·min(sd, IQR/1.349)·N^(−1/5).
- Сетка: n() точек (как в Stata), подпись внизу: `kernel = epanechnikov, bandwidth = 336.9905`.
- С `normal` — наложить плотность N(mean, sd). Легенда: «Kernel density estimate», «Normal density».

### acprplot x, lowess

- Дополненная модель: y на X + x², получить остатки ẽ, коэффициенты b_x, b_x².
- Ось Y: ẽ + b_x·x + b_x²·x² («Augmented component plus residual»), ось X: x.
- Линии: МНК-прямая этой величины по x и lowess.
- lowess как в Stata: bwidth 0.8, трикубические веса, локальная линейная регрессия, без робастных итераций.

### rvfplot

Scatter: e против ŷ, оси «Residuals» и «Fitted values», `yline(#)` — горизонтальная линия.

## Пояснения (модуль `explain/`)

Для каждой команды — функция `explain(result) → { verdict, text, reportPhrase }`. Тексты простые, без терминов (или с термином и расшифровкой в скобках). Числа подставляются из результата.

| Команда | Вердикт | Логика |
|---|---|---|
| regress | ✓/✗ по Prob > F | Модель значима или нет. R² «объясняет X% различий». Adj R² сильно ниже R² — «есть лишние факторы». Список значимых (P>\|t\| < 0,05) с фразой «при росте X на 1 цена растёт/падает на Coef. при прочих равных». Незначимые одной строкой. Про `_cons` — «не интерпретируем» |
| linktest | ✓ если p(_hatsq) ≥ 0,05 | П1: форма модели. Предупреждение «шапку не смотреть — это вспомогательная регрессия» |
| ovtest | ✓ если p ≥ 0,05 | П1: пропущенные переменные / нелинейность |
| vif | ✓ если все VIF < 10 | П2. Перечислить факторы с VIF > 10, показать √VIF: «ошибка завышена в N раз» |
| swilk | ✓ если p ≥ 0,05 | П5 |
| hettest | ✓ если p ≥ 0,05 | П4 |
| imtest | ✓ если все p ≥ 0,05 | П4 + П5, плюс предупреждение о насыщении |
| sum (по остаткам) | ℹ | Если переменная — остатки последней модели и \|mean\| ≈ 0: «П3 выполнена». Расшифровать научную запись: 3.58e-06 = 0,00000358 |
| графики | ℹ | Как читать конкретный график («линия вверх — прямая связь», «ищите воронку», «синяя близка к красной — хорошо») |
| corr | ℹ | Шкала Чеддока: <0,3 нет, 0,3 слабая, 0,5 средняя, 0,7 сильная, 0,9 очень сильная |

**Главное правило** повторять везде, где есть p: «p < 0,05 → H0 отвергаем. Для факторов и модели хорошо маленькое p, для проверок предпосылок — большое».

Отдельная панель «Итог по предпосылкам» (сайдбар или кнопка): таблица П1–П5 со статусами, которые обновляются по мере запуска тестов, и кнопка «Собрать общий вывод» (шаблонный текст из всех результатов).
